# Security Policy

## Supported versions

Security fixes are provided for the latest public release of Ray's Loader.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/PKRReaperr/Rays-Loader/security/advisories/new) for suspected security problems.

Do not open a public issue for a vulnerability. Do not include passwords, browser cookies, authentication tokens, private media URLs, or other sensitive information in public issues, screenshots, or download logs.

Include the Ray's Loader version, Windows version, affected feature, reproduction steps, and potential impact. Rayware Inc. will review the report and follow up through the private advisory when more information is needed.
